摄像头脚位保持原样；只把 TFT 从 ESP32 移到 STM32。双机通讯改为 UART，只需 2 根信号线 + 共地。两端 3.3V 各自供电。

2. ESP32-S31 → STM32F103CBT6（UART 链路，2 根信号）

4. 链路协议速查

每行一包 485 字节：A5 5A | 帧号 | 行号(0~239) | 异或校验 | 480 字节 RGB565(高字节在前)。双 magic 便于错位后重新同步。STM32 收到一行立刻写屏，不缓存整帧（只有 20KB SRAM）。理论上限约 1.7fps，实际约 1fps。

顶栏调试：V6 为 UART 版（V5 是旧 SPI 版）；K 有效行、T 超时、C 校验错、G magic 错、W 行号错、L 主循环心跳。
