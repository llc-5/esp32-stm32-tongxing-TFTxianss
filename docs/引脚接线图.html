SCK 和 MOSI 接反是最常见的接错，现象是屏上 G（magic 错）计数飞涨。
GPIO40/41 空着（40 是 strapping 脚）。线长建议 <20cm；若 C/G 持续增长，两端同时把 LINK_SPI_HZ 从 8000000UL 改成 4000000UL 重编重烧。

PA5/PA7 原来是 GPIO 逐位翻转模拟 SPI（写一帧要 390ms），现在交给硬件 SPI1，同样数据量只要约 51ms。 屏对时钟敏感，若出现花屏/斜纹，把 ili9341.h 里的 LCD_SPI_BR 从 0x01（18MHz）改成 0x02（9MHz）。

4. 链路协议速查

每行一包 485 字节：A5 5A | 帧号 | 行号(0~239) | 异或校验 | 480 字节 RGB565(高字节在前)。双 magic 便于错位后重新同步。STM32 用 DMA 整包接收（485 字节搬完才打扰 CPU），收到一行立刻写屏，不缓存整帧（只有 20KB SRAM）。

性能：链路 485B×240 行÷8MHz ≈ 116ms/帧，屏写入约 51ms/帧，串行相加预期 5~6fps（UART 版约 1fps）。

顶栏调试：V7 为 SPI 版（V6 是旧 UART 版，接线不同，必须重烧）；K 有效行、T 超时、C 校验错、G magic 错、W 行号错、R 一包里最多收到过多少字节（485 = 收满，0 = 时钟没进来）。
